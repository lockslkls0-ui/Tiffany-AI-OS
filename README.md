🇫🇷 VERSION FRANÇAISE — CE QUE FAIT TIFFANY AI-OS v48.6
===============================================================================
Conçu et testé sur un PC portable Toshiba Portégé R830 (Intel Core i3, 8 Go RAM),
Tiffany AI-OS v48.6 est un environnement d'assistance vocale et système 100 % local,
souverain, sans cloud et ultra-léger pour Linux.

- 📱 Compagnon Mobile Wi-Fi & QR Code Automatique :
  Pilote ton PC depuis ton téléphone en scannant le QR Code généré à l'écran,
  avec synchronisation en direct sur le bureau, code PIN sécurisé (SHA-256)
  et téléchargeur MP3 YouTube conversationnel.
- 🎙️ Oreille Continue & Réveil Vocal Instantané (Vosk FR) :
  Écoute locale sans abonnement avec fenêtre de suivi de 18s et correcteur phonétique.
- ⚡ Double Cerveau Hybride (< 0,05 s en Bash + IA locale Ollama) :
  • Réflexes instantanés (< 0,05 s) : 39 boutons graphiques et 28 outils terminal
    (urgence CPU, volume, luminosité, mode froid/boost, purge RAM/ZRAM, météo IP,
    recherche de fichiers, capture d'écran, coffre-fort chiffré AES-256).
  • Cerveaux neuronaux locaux (Ollama) : tiffany-flash (397 Mo), qwen2.5:1.5b et
    qwen2.5-coder:1.5b.
- 🛡️ Sentinelle Thermique, Santé SMART, Lecture PDF & Web-IA :
  Surveillance CPU permanente (systemd), résumés PDF en 2s, dossiers Web-IA et
  planificateur vocal/graphique.
