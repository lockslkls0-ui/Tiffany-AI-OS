# 📜 Crédits & Licences Tierces — Tiffany AI-OS v48.6

**Tiffany AI-OS** (scripts d'orchestration, architecture hybride, console unifiée, sentinelle thermique et interface graphique) est une création originale développée pour Linux.

Ce projet s'appuie sur les briques logicielles libres suivantes (installées ou téléchargées localement chez l'utilisateur) :
- **Ollama** — Moteur d'inférence LLM local (Licence MIT)
- **Qwen 2.5** — Modèles de langage locaux (Licence Apache 2.0)
- **Vosk API & Modèle FR** — Reconnaissance vocale hors-ligne (Licence Apache 2.0)
- **Piper TTS & Voix Siwis** — Synthèse vocale neuronale locale (Licence MIT / CC-BY)
- **eSpeak-NG** — Synthèse vocale système légère installée via le gestionnaire de paquets Linux (Licence GPLv3, exécutée en tant que binaire système externe)
